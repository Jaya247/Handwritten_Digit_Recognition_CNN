# Handwritten Digit Recognition Using Deep Learning and CNN

## Project Overview       
This project uses Deep Learning and a Convolutional Neural Network (CNN) to recognize handwritten digits from 0 to 9. It uses the MNIST dataset to train and evaluate the model.

## Problem Statement
Handwritten digits can vary in shape, size, and writing style, making automatic recognition challenging. This project aims to classify handwritten digit images accurately using a deep learning model.

## Proposed Solution
A CNN model is built using TensorFlow and Keras. The model learns patterns from handwritten digit images and predicts the digit represented by an input image.

## Key Features
- Recognizes handwritten digits from 0 to 9.
- Trains a CNN model on the MNIST dataset.
- Evaluates model performance using test accuracy.
- Displays training and validation accuracy graphs.
- Predicts digits from test images.

## Technologies Used
- Python
- Google Colab
- TensorFlow and Keras
- NumPy
- Matplotlib
- MNIST Dataset
- Convolutional Neural Networks (CNN)

## Dataset
The project uses the MNIST dataset, which contains grayscale handwritten digit images of size 28 × 28 pixels.

## How to Run
1. Open the project notebook in Google Colab.
2. Run the code cells sequentially.
3. Load the MNIST dataset.
4. Train the CNN model.
5. Evaluate the model and view digit predictions.

## Results
The notebook displays the model's test accuracy, training graphs, and sample digit predictions after execution.
